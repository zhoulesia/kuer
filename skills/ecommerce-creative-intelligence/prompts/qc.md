# E-commerce Creative QC

Check every generated asset against:

## Product
- same identity
- same shape and proportions
- same color/material/texture
- same logo position
- same component count

## Visual
- no deformation
- no duplicate product
- no malformed hands or props
- no impossible geometry
- no watermark

## Text
- spelling
- grammar
- translation consistency
- numeric accuracy
- unit accuracy

## Claims
- all quantitative, certification, medical, safety, and performance claims must be verified

## Platform
- correct aspect ratio
- readable mobile composition
- platform-specific requirements respected

Return PASS or FAIL per image and regenerate only failed assets. If Product Master is invalid, stop and rebuild it first.
