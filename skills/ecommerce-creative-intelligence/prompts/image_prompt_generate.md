# Image Prompt Generator

Build each prompt from these layers in order:

1. Product Master: exact verified identity.
2. Creative Strategy: positioning, visual direction, and approved opportunity.
3. Image Plan: composition, scene, camera, props, human interaction, and objective.
4. Platform adapter: aspect ratio, safe area, mobile readability, and platform constraints.
5. Copy Master: only approved translated copy.
6. Negative constraints: no deformation, invented components, extra logos, duplicate products, incorrect text, incorrect dimensions, competitor branding, or watermark.

The prompt must preserve the exact physical product while using only abstract market patterns. Never request replication of an individual competitor image.
